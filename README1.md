Responsive Landing Page

SkillCraft Technology — Web Development Internship (Task 01)

📌 Project Overview

This project is a responsive landing page developed using HTML, CSS, and JavaScript. It features an interactive navigation menu that changes its appearance when scrolling and provides hover effects on navigation links.

The website is designed to provide a smooth and user-friendly experience across different screen sizes.

✨ Features

- Fixed navigation bar.
- Navigation bar changes color on scrolling.
- Interactive hover effects.
- Responsive mobile navigation menu.
- Smooth scrolling between sections.
- Home, About, Services, and Contact sections.
- Modern and attractive user interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Right-click and select Open with Live Server, or open the HTML file directly in a browser.
